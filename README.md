# PSI Meter ESP — Android releases

A minimalist training experience in attention, intuition and timing.

[Download the latest signed APK](https://github.com/iskrantxusa/PSI-Meter-ESP-releases/releases/latest/download/PSI-Meter-ESP.apk) · [Website](https://extra-sense-lab.com/en/psi-meter-esp) · [Release history](https://github.com/iskrantxusa/PSI-Meter-ESP-releases/releases)

Requires Android 6.0 or newer. Download the APK and open it. If Android asks, allow your browser to install apps from this source, then confirm installation.

To update, install the newer APK over the existing app without uninstalling it. Releases use the same signing key, preserving your training and settings. Updates are downloaded manually.

Each release includes SHA256SUMS.txt. You can check the downloaded APK with PowerShell:

```powershell
Get-FileHash .\PSI-Meter-ESP.apk -Algorithm SHA256
```

App signing certificate SHA-256:


This repository contains release documentation and compiled binaries only. The application source repository is private. Progress in the app is not a validated measure of ESP.
